Live Subscriber Count

YouTube Studio does not send the live subscriber total through chat. A Tampermonkey script reads the number on screen and sends it to Streamer.bot. Pick the browser you will leave open.

  1. Install the Tampermonkey extension in the browser you selected.
  2. Create a new Tampermonkey script, replace the template with the code from the Userscript view, and save it. It runs on studio.youtube.com.
  3. In Streamer.bot, turn on the two actions for this browser and turn off the other pair. The import already includes them.
  4. Launch runs when Streamer.bot opens and opens YouTube Studio. Close runs when the YouTube broadcast ends and closes that window.
  5. Leave that Studio window open and not minimized. The count does not update if Streamer.bot is closed, or if the window is closed or minimized.
  6. The script calls the action Update Sub Count with liveSubCount on ws://127.0.0.1:8080/. Use the same port as this page. It does not send a WebSocket password.

Import JSON
Streamer.bot cannot create globals from the browser. Use this action to write memberEmojiMap.

In Streamer.bot, create an action named GTA_SetMemberEmojiMap (or keep API_SaveEmotes). Add a C# sub-action and paste this code. The same file is streamerbot/GTA_SetMemberEmojiMap.cs.

using System;
using Newtonsoft.Json.Linq;

public class CPHInline
{
    public bool Execute()
    {
        string json = "{}";
        if (CPH.TryGetArg("emotesJson", out string raw) && !string.IsNullOrWhiteSpace(raw))
        {
            json = raw.Trim();
        }

        try
        {
            var token = JToken.Parse(json);
            if (token == null || token.Type != JTokenType.Object)
            {
                json = "{}";
            }
            else
            {
                json = token.ToString(Newtonsoft.Json.Formatting.None);
            }
        }
        catch
        {
            json = "{}";
        }

        CPH.SetGlobalVar("memberEmojiMap", json, true);
        return true;
    }
}

Setup Instructions

  1. In Streamer.bot, click the Import button (top-left), paste the code below, then click Import.
  2. Find the action [GTA_Initialize Globals] in the Actions list, right-click, and choose Test. This creates viShoutOuts and viChatHighlight.
  3. Go to Servers, then WebSocket Server, and enable it. Use the same Host, Port, and Password as the General tab.
  4. (Optional) Open Auto Import Youtube members (File Watcher) and set the folder for your YouTube members CSV.
  5. Copy a browser-source URL from this page into OBS Studio.
  6. Test everything with the buttons on the Test tab.

Note: The global variable names on the Shoutout and Q&A tabs must match the actions (viShoutOuts / viChatHighlight).
