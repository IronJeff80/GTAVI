Setup Instructions

  1. In Streamer.bot, click the Import button (top-left) → paste the code below → click Import.
  2. Find the action [GTA_Initialize Globals] in the Actions list → right-click → Test (this creates the required global variables viShoutOuts and viChatHighlight).
  3. Go to Servers → WebSocket Server and enable it. Use the same Host / Port / Password shown in the General tab of this page.
  4. (Optional) Open the Auto Import Youtube members (File Watcher) action and set the folder path for your YouTube members CSV if you want automatic member imports.
  5. Use the Generate URLs section at the bottom of this setup page and add the Browser Source(s) into OBS Studio.
  6. Test everything using the buttons on the Test tab.

Note: The global variable names in the Shoutout and Q&A tabs must match the ones set by the actions (viShoutOuts / viChatHighlight).
